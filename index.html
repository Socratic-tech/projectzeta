Upgrade an Existing Tracker

Keep the existing spreadsheet and records. Upgrade the security model in place.

Do not create a new spreadsheet. The upgrade preserves students, evaluations, job sites, tasks, and existing report-viewer codes.
  1. 1

    Open the existing school spreadsheet

    Optional but recommended: make a backup copy first. Continue working in the original production spreadsheet.

  2. 2

    Replace the two Apps Script files

    In the Google Sheet choose Extensions → Apps Script. Replace Code.gs. For the Sidebar, click + beside Files → HTML, name it exactly Sidebar, then paste the complete Sidebar source. If Sidebar.html already exists, replace its entire contents. Save the project.

    description Open the current Code.gs copy/paste document
    code Open & copy the Sidebar source code
  3. 3

    Refresh the spreadsheet

    Refresh or reopen the Sheet. V3 automatically migrates the security tables, keeps existing data, and rotates the job-site entry token.

    Old job-site QR codes stop working at this point.

  4. 4

    Create the first personal administrator

    In the Sheet choose Vocational Tracker → Setup & Credentials. Add the administrator's name and school email. Their personal code is emailed and works for both Admin and Reports.

    Once a personal admin exists, the old shared Admin password is permanently retired.

  5. 5

    Approve email permission if Google asks

    V3 can email admin and report-viewer codes. The spreadsheet owner may be asked to authorize Apps Script to send email the first time.

  6. 6

    Update the existing Web App deployment

    Go to Deploy → Manage deployments → Edit and choose New version. Keep Execute as: Me and Who has access: Anyone.

    Do not create a new deployment. Keep the same /exec URL.

  7. 7

    Verify the upgrade

    Use the guided upgrade page to confirm the existing deployment reports API v3 and schema v3.

  8. 8

    Generate and replace the entry QR

    Sign into Admin with a personal admin code, generate the new job-site QR, and replace every old printed QR. Shared devices scan the new QR once.

  9. 9

    Run one quick cutover test

    Submit a test entry, confirm a report-only code opens Reports but not Admin, and confirm an admin code opens both Admin and Reports.
