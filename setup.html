School Setup Wizard

Follow these steps to set up the Vocational Tracker for your school.

school

1. Create Your School Spreadsheet

Every school needs their own private copy of the Vocational Tracker spreadsheet.

Make a Copy of the Spreadsheet
Tip: Save the spreadsheet to a shared Google Drive folder your whole team can access.
verified_user

2. Access & Authorize the Script

Your spreadsheet already contains the Vocational Tracker backend script.

  1. Open your copied spreadsheet.
  2. Go to Extensions → Apps Script.
  3. Click the Run ▶ button for any function.
  4. Google will ask you to authorize — select your account and click Allow.
Note: Google may show a warning that the app is "unverified." This is normal for school-managed scripts. Click Advanced → Go to Vocational Tracker (unsafe) to proceed.
settings

3. Run initialSetup()

This one-time step creates all the required sheets in your spreadsheet: Students, Entries, Settings, Sites, and Tasks. You only need to do this once.

A

Open the Apps Script editor

In your spreadsheet, click Extensions in the top menu, then select Apps Script. A new tab will open showing the script editor.

B

Select initialSetup from the function dropdown

Near the top of the editor you'll see a dropdown that may say "Select function" or show a function name. Click it and choose initialSetup from the list.

Set your Admin password in the Settings sheet

Click the Settings tab in your spreadsheet. You'll see a default password of voc123 in cell B2. Change this to a password your admin team will use to access the Admin panel.

Important: Change this before sharing the system with anyone. The password is stored in plain text in the sheet — keep the spreadsheet access restricted to admin staff only.
✓ Done? If you can see all five sheet tabs and your password is set, you're ready to continue.
rocket_launch

4. Deploy the Web App

This creates the URL that connects the app to your spreadsheet.

  1. In the Apps Script editor, click Deploy → New Deployment.
  2. Click the gear icon next to "Select type" and choose Web App.
  3. Set Execute as: Me.
  4. Set Who has access: Anyone.
  5. Click Deploy.
  6. Copy the Web App URL — it starts with https://script.google.com/macros/s/
Tip: Every time you edit the script code after this, you'll need to create a new deployment version for the changes to take effect. The URL stays the same.
link

5. Connect Your Backend

Paste the Web App URL from the previous step to connect this app to your spreadsheet.
