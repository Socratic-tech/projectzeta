Vocational Tracker Help

Entry staff, report viewers, and administrators all use different levels of access.

qr_code_2

Job-site Entry

Scan the QR code provided by your program coordinator. The secure link contains a restricted entry code that allows the form to load student, site, and task choices and submit an evaluation. It does not provide access to Reports or Admin.
No. Job-site entry is intentionally the simplest workflow: scan the authorized QR code, complete the form, and submit. You still enter your name in the Evaluator field so the record shows who completed the evaluation.
The public web address by itself is not enough to enter data. On a device that has never scanned the job-site QR, you must scan the current QR code first. After a successful scan, the device can remember the secure entry connection for future use.
Your coordinator may have rotated the entry code. Rotation immediately disables every older QR and saved entry link. Scan the newly issued QR code and the device will save the new connection.
key

Reports & Administrator Access

A spreadsheet administrator adds you from Vocational Tracker → Setup & Credentials inside the Google Sheet. Your personal code is generated and emailed to the address they enter.
No. An active administrator automatically has Reports access. Use the same personal administrator code on both the Admin and Reports pages.
No. The tracker stores only a one-way hash of a personal administrator code. The original may still be in the email that was sent when it was created. If it is truly lost, a spreadsheet administrator can generate a replacement code for only that person. Everyone else's code keeps working.
Yes. Report-only viewer codes can be re-emailed from the spreadsheet's Setup & Credentials sidebar. Administrator codes cannot be recovered, so the equivalent Admin action generates a new code.
Administrators can submit a request directly from the Admin page. Every request is saved in the spreadsheet's Feature Requests tab. If a support email is configured in Vocational Tracker → Setup & Credentials, the request is emailed there automatically too.
A disabled report viewer immediately loses Reports access. A disabled administrator loses both Admin and Reports access because those permissions are tied to the same personal admin code.

Filling Out an Evaluation

  • 0 — Not at All: Student did not perform the skill.
  • 1 — Direct Prompting: Required direct or step-by-step prompting.
  • 2 — Indirect Prompting: Needed a verbal reminder, cue, or gesture.
  • 3 — Independent: Performed the skill without prompting.
  • 4 — Helping/Teaching: Performed the skill and helped or modeled it for others.
Behavioral Skills are the core work-readiness skills scored at every site. Job Tasks are site-specific duties configured by an administrator. Job Tasks can be marked N/A when that task did not occur during the shift.
Contact your program coordinator. Only active students appear in the entry dropdown. An administrator can add the student or reactivate an existing student from the Admin page.
Notes are optional but useful when a score alone does not tell the whole story. Record relevant context, strong performance, challenges, or anything the student's team should understand later.

Submitting & Troubleshooting

The page waits for a real response from the tracker before showing Saved!. If the server rejects the entry or the connection fails, the form shows an error instead of pretending the entry was recorded.
  1. Confirm the device has Wi-Fi or cellular data.
  2. Re-scan the current job-site QR code.
  3. Close the tab and open it again.
  4. If the secure link was rotated, use the newly printed QR.
  5. If the problem continues, contact your program coordinator.
Not from the entry form. Contact your program coordinator if a submitted record needs correction.
