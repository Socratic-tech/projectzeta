Loader code (one-time install)

Release 3.1.0. After this, backend updates install with one click and can be undone.

  1. In your school's Google Sheet choose Extensions → Apps Script.
  2. Open Code.gs, select everything, and paste the code below in its place. Keep Sidebar.html as it is.
  3. Click Save, choose vtbInstallNow in the function list, then Run. Approve the permission Google asks for.
  4. Deploy → Manage deployments → pencil icon → New version → Deploy. This is the last time you redeploy by hand. The /exec URL stays the same.

Student data, admin and viewer codes and QR links are not affected.
